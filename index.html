Ёвари зеҳни сунъӣ барои нақша, молия ва ғояҳо. Барои ҷавобҳои AI бояд API-и худро пайваст кунӣ; калиди API-ро дар ин веб-саҳифаи оммавӣ нагузор.

Сервер бояд дархости POST-и JSON-ро бо { messages: [...] } қабул кунад ва ҷавоби JSON бо { reply: "..." } баргардонад. Калиди API бояд танҳо дар сервер нигоҳ дошта шавад.

Салом! Метавонам маълумоти дар ҳамин барнома сабтшударо ҷамъбаст кунам ва барои нақша маслиҳат диҳам.

Ҳолати маҳаллӣ аз маълумоти дохили барнома истифода мебарад, аммо модели забонии пуриқтидор нест. Барои AI-и онлайн endpoint-и сервер лозим аст.
