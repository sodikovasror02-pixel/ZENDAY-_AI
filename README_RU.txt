ZENDAY с модулем AI.
Локальный режим умеет анализировать задачи и финансовые записи, но не является полноценной языковой моделью.
Для подключения настоящего онлайн AI нужен ваш сервер HTTPS endpoint, который принимает POST JSON {messages, language, context} и возвращает JSON {reply:"..."}.
Не вставляйте секретный API-ключ в index.html или в общедоступный репозиторий. Храните ключ только на сервере.
Чтобы обновить GitHub Pages, замените index.html в корне репозитория этой версией и выполните commit.
